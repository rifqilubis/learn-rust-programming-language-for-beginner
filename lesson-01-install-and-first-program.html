Lesson 01 Setup 12 min

Install Rust and run a program

One toolchain, one project, one line of output. By the end of this lesson a program you wrote is running on your machine.

01What you are actually installing

Rust ships as three pieces that work together. You install them once, through a tool called rustup, and then stop thinking about it.

  • rustc is the compiler. It turns a .rs file into a program.
  • cargo is the project tool. It creates projects, downloads libraries, builds, and runs tests.
  • rustup is the installer. It manages which version of the two above you have.

You will call cargo almost every day and rustc almost never. That is normal.

02Install

On Linux or macOS, run this in a terminal and follow the prompts. The default options are the right ones.

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

On Windows, download and run rustup-init.exe from rustup.rs. It will offer to install the Microsoft C++ build tools if they are missing, and you should accept, because the linker lives there.

Close the terminal and open a new one so the path change takes effect, then check the install:

rustc --version && cargo --version

You should see two version numbers. If you see a command not found error, the installer's path line did not reach your shell, so open a fresh terminal or run source ~/.cargo/env.

03Create a project

Never start with a bare .rs file. Cargo needs a folder with a manifest to know how to build and run your code.

cargo new hello_rust && cd hello_rust

That gives you this:

hello_rust/
├── Cargo.toml
└── src/
    └── main.rs

Cargo.toml is the manifest: the project name, the version, and later the libraries you depend on. src/main.rs is your program, and it already contains a working one.

04Read the program

Open src/main.rs. It contains exactly this:

Three things are happening. fn main() declares the entry point, the function the operating system calls when the program starts. The braces hold the body. println! is a macro, which you can tell by the exclamation mark, and it prints a line of text followed by a newline.

Those quotation marks matter. Without them you would be naming a variable, not writing text.

05Run it

From inside the project folder:

cargo run

The first run compiles, so it takes a second or two. Every run after that reuses the build, so it is instant until you change a file. You should see the greeting printed under a Running line.

Two more commands

cargo build compiles without running. cargo check checks for errors without producing a program, and it is the fastest of the three, so reach for it while you are editing.

06Make it yours

Change the text and add a second line. The {} pair is a slot, and the value after the comma fills it, in order.

Run it with cargo run and confirm both lines appear.

07If something breaks

Compilers complain, and Rust's complaints are unusually specific. Read the first error only, fix it, then run again, because later errors are often knock-on effects.

Notice the shape of the message: an error code, the file and line, a caret pointing at the exact character, and usually a suggested fix. Every error code has a full page of explanation, which you can read with rustc --explain E0308 or any other code the compiler prints.
