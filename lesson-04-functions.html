Lesson 04 Basics 14 min

Functions and return values

A function is a name for a piece of work. Rust adds one rule that surprises everyone: the last expression is the return value, with no semicolon.

On this page

  1. Declaring one
  2. Expression versus statement
  3. Early return is still available
  4. Functions that change their argument
  5. Functions that return nothing
  6. Exercise

01Declaring one

Every parameter needs a type and the return type follows an arrow. Nothing is inferred across a function boundary, which is why the signature alone tells you how to call it.

Look at the body of add. There is no return and no semicolon. The expression a + b is the last thing in the block, so it is the value of the block, and the block is the function body.

02Expression versus statement

An expression produces a value. A statement does not. A semicolon turns an expression into a statement, which is exactly why adding one to the last line breaks the function.

This is the most common early error in Rust, and the message names the fix. Remove the semicolon.

03Early return is still available

For guard clauses, return reads better than a deeply nested expression.

&'static str means a borrowed string that lives for the whole program. String literals are always that, so returning one needs no allocation.

04Functions that change their argument

By default a function cannot change what you pass it. To allow it, the parameter must be a mutable reference and the caller must pass one.

The &mut in the signature is a visible warning at the call site that this call can change your value. Lesson 7 covers the rules behind it.

05Functions that return nothing

Omit the arrow. The return type is (), the unit type, and the function is called for its effect.

06Exercise

Write celsius_to_fahrenheit(c: f64) -> f64 and use it to print the conversions for 0, 100, and -40 in the form 0.0C = 32.0F. Then write min_max(a: i32, b: i32) -> (i32, i32) that returns the pair in order, and print min 3, max 9 for the inputs 9 and 3.

Show a hint

The formula is c * 9.0 / 5.0 + 32.0. For the second, return (a, b) or (b, a) depending on the comparison, and destructure the result at the call site with let (low, high) = ....

Expected output

100.0C = 212.0F
-40.0C = -40.0F
min 3, max 9
