Lesson 08 Data 16 min

Structs and methods

A struct names a group of related values. An impl block attaches behavior to it. Together they are how you model a real thing in Rust.

On this page

  1. Defining and building one
  2. Deriving Debug
  3. Methods
  4. Associated functions
  5. Updating a struct
  6. Exercise

01Defining and building one

Fields are named and typed. Build a value with the same names, in any order.

Field access is a dot. There are no getters to write unless you want validation.

02Deriving Debug

Add #[derive(Debug)] above the struct and you can print the whole value with {:?}. It costs nothing at runtime and it is the first thing to add while building.

{:#?} is the pretty version, one field per line.

03Methods

An impl block holds functions that belong to the type. A method takes &self to read, &mut self to change, or self to consume.

restock needs &mut self because it changes a field, and bolt has to be declared mut. The compiler will tell you both facts if you forget.

04Associated functions

A function in an impl block without self is called on the type, not on a value. Part::new(...) is the conventional constructor, because Rust has no constructor keyword.

Self means the type the impl block is for. The shorthand quantity, fills the field of the same name from the parameter, which keeps constructors short.

05Updating a struct

Struct update syntax builds a new value from an old one, taking the remaining fields by move.

06Exercise

Model a Book with title, author, and pages. Add Book::new and a method reading_time that returns minutes at 2 pages per minute. Create The Hobbit by Tolkien with 310 pages and print The Hobbit by Tolkien: 155.0 minutes.

Show a hint

Divide as f64: self.pages as f64 / 2.0. Return f64 and print with {:.1}. Inside an impl Book block, the constructor takes &str parameters and builds String fields with to_string().
