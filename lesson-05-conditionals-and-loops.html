Lesson 05 Basics 15 min

Decisions and repetition

if is an expression, loops return values, and there is no do-while to trip over. The control flow is small enough to learn in one sitting.

On this page

  6. Exercise

01if is an expression

The condition must be a real bool. There is no truthiness, so if count is an error where if count > 0 is not.

Because if is an expression, it can produce a value, which makes this legal and idiomatic:

Both branches must produce the same type, or the compiler cannot know what status is.

02for over a range

for walks anything iterable. A range with two dots excludes the end, three dots includes it.

Prefer for over indexing. It cannot run off the end of the collection, and it reads as what you mean.

03while, and loop

while repeats while a condition holds. loop repeats until you break, and it can return a value from the break.

break value is how loop hands back a result, which is handy when the exit condition is discovered in the middle of the body.

04Iterating a collection

Iterating an array by value gives you copies of the elements. Iterating with .iter() gives you references, and .iter_mut() gives you mutable references.

The star in *slot += 5 follows the reference to the value behind it. Lesson 7 explains what that means.

05Leaving early

break leaves the nearest loop, continue skips to the next round, and labels let you target an outer loop when loops nest.
