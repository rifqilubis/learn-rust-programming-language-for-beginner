Lesson 03 Basics 16 min

Numbers, text, and tuples

Rust has a small set of built-in types and no implicit conversions between them. Learn the five you will use daily and the rest follow.

On this page

  1. Whole numbers
  2. Decimals
  3. Text: char and String
  4. Booleans
  5. Tuples group values of different types
  6. No silent conversions

01Whole numbers

Integers come in signed (i) and unsigned (u) form, in widths of 8, 16, 32, 64, and 128 bits, plus isize and usize which match the machine's pointer size.

The underscore in 18_000_000_000 is a readability aid, not syntax you have to remember. usize is what you use for lengths and indexes, because that is what the standard library expects.

If you do not write a type, Rust infers i32 for integers. That default is fast on every platform, so let it work unless a specific size is part of the problem.

02Decimals

Floating point comes as f32 or f64, and the default is f64. Use it for measurements, money arithmetic that has been thought through, and anything scientific. Do not use it for exact currency, because 0.1 plus 0.2 is not 0.3 in binary floating point.

{:.2} means print with two decimal places. The number after the colon is a format specification, and it works on any float.

03Text: char and String

char is one Unicode scalar value in single quotes. String is growable text you own, in double quotes.

&str, the type of literal, is a borrowed view of text. You will meet it constantly as a function parameter, and lesson 7 explains why it exists. For now, the rule of thumb is: String when you build or own text, &str when you only read it.

04Booleans

bool is true or false and nothing else. Rust will not accept 0 or 1 in its place, unlike C.

05Tuples group values of different types

A tuple is a fixed set of values, each with its own type. Reach for one when you need to return two related things without inventing a struct.

Access by position with .0 and .1, or destructure into names with a pattern. {:?} is the debug format, the one to reach for when you want to see a value during development.

06No silent conversions

Adding an i32 to an i64 is an error, not a promotion. You convert explicitly with as.

Why so strict

Implicit narrowing is where a lot of production bugs come from. Rust makes the conversion visible so you cannot do it by accident, and the as keyword is your signal to check the range.

Exercise

Create a tuple holding a product name, a quantity, and a unit price. Print a single receipt line using the debug format for the tuple and a two decimal format for the computed total.

Show a hint

The name is a &str or String, quantity an integer, price an f64. Multiply quantity as f64 by price.
