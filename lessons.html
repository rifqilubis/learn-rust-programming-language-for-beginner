Every lesson, in the order they build

The first six lessons give you the language. The next three give you the ownership model, which is the part that makes Rust Rust. The last three turn it into programs you can keep.

Setup

01 Install Rust and run a program One toolchain, one project, one line of output. By the end of this lesson a program you wrote is running on your machine. 12 min Not started

Basics

02 Variables, mutability, and shadowing Rust makes you say when a value can change. That one word removes a whole category of bugs, and it takes ten minutes to get used to. 15 min Not started 03 Numbers, text, and tuples Rust has a small set of built-in types and no implicit conversions between them. Learn the five you will use daily and the rest follow. 16 min Not started 04 Functions and return values A function is a name for a piece of work. Rust adds one rule that surprises everyone: the last expression is the return value, with no semicolon. 14 min Not started 05 Decisions and repetition if is an expression, loops return values, and there is no do-while to trip over. The control flow is small enough to learn in one sitting. 15 min Not started

Ownership

06 Ownership: who holds the value Every value has exactly one owner. When the owner goes out of scope the value is freed. This is the idea the rest of Rust is built on. 18 min Not started 07 Borrowing instead of moving A reference lets a function read or change a value without taking ownership of it. The rules are two lines long, and they prevent data races at compile time. 17 min Not started

Data

08 Structs and methods A struct names a group of related values. An impl block attaches behavior to it. Together they are how you model a real thing in Rust. 16 min Not started 09 Enums, match, and Option An enum says a value is one of several things. match makes you handle every one of them. Together they replace null and most boolean flags. 18 min Not started 10 Vectors and strings Two growable collections cover most programs: a list of values, and text you build at runtime. Both own their contents and both are used constantly. 17 min Not started

Real programs

11 Recoverable errors with Result A failure you can do something about is a value, not an exception. Result carries either the answer or the reason, and the question mark passes it along. 18 min Not started 12 Modules, tests, and what next Split code into modules, prove it works with tests, and then go build something. The last lesson is mostly about the habit. 16 min Not started
